# macbastion

A defensive security audit tool for macOS.

Scans your Mac for common misconfigurations, persistence mechanisms, and orphaned permissions left behind by uninstalled software.

## Status

Early development. Not ready for production use.

## Planned modules

- Port scanner (listening services audit)
- LaunchAgents / LaunchDaemons analyzer
- TCC permissions inspector
- Code signature verifier
- Persistence detection
