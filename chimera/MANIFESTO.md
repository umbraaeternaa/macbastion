# 🐉 МАНІФЕСТ CHIMERA

> Ми будуємо організм, а не toolkit.

---

## 1. ОДНА МАШИНА — ОДИН ВЛАСНИК

CHIMERA захищає одного. Назавжди. Без хмар, без серверів, без telemetry.
Якщо щось іде в мережу — це підозра.

## 2. МОДУЛІ — ЦЕ ОРГАНИ

Кожен модуль робить одне. Бездоганно. Якщо модуль ламається —
решта живе. Якщо орган не робить нічого унікального —
його не існує.

## 3. МОЗОК ВАЖЛИВІШИЙ ЗА ОРГАНИ

Цінність CHIMERA — не в окремих модулях. Цінність — в корі (core)
яка координує. Це emergent intelligence.

## 4. БЕЗ ІМІТАЦІЙ

Якщо щось не працює — пишемо це чесно. Краще порожня функція
з TODO ніж заглушка яка вдає роботу.

## 5. ГІБРИДНИЙ СТЕК — З ПРИЧИНОЮ

- **Python** — оркестрація, UX
- **C** — system calls, performance
- **ARM64 Assembly** — там де потрібен контроль над кожним тактом процесора

Не "тому що круто". Тільки коли потрібно.

## 6. ВІДКРИТО, АЛЕ НЕ ДЛЯ ВСІХ

Код публічний. Але це інструмент, не продукт для масс.
Користувач має розуміти що робить.

## 7. ПОВІЛЬНО — ТЕ ЩО ВИЖИВЕ

Ми будуємо рік. Не тиждень. Якщо щось вимагає швидкого
рішення — це не для CHIMERA.
