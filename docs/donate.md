# Supporting CHIMERA Development

CHIMERA is free, open source, and will stay that way.

If the project is useful to you and you want to support continued 
development, you can contribute via Monobank Jar (Ukraine):

**Link:** https://send.monobank.ua/jar/AHaziFXjYX

**QR Code:** ![Monobank QR Code](donate.png)

## What donations support

- Time to finish remaining core modules (registry, lifecycle, server)
- Native module implementation (CHAFF, ECHO, MIRROR, ORACLE, PULSE, VAULT, TETHER, PURGE)
- Hardware testing across M1/M2/M3 variants
- Documentation maintenance and translations
- Conference travel for security talks

## What donations are NOT for

- Premium tier (CHIMERA stays free regardless of donation volume)
- Influencing roadmap decisions
- Removing transparency
- Backdoors or compromises to the no-recovery-paths principle

The CHIMERA MANIFESTO is non-negotiable. Donations support the operator's 
time to build it, not changes to what is being built.
