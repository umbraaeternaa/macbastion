# 🥷 Стелс-дисципліна — памʼятка (Umbra)

> Інструменти (CHIMERA + стелс-мімікрія) — це фундамент. **Непробивним тебе робить ПОВЕДІНКА.**
> Цей список — як користуватись стеком, щоб він працював на максимум.

## 1. Розділення персон — ЗАКОН
- **Persona A** (Samsung, справжнє імʼя, Google, банк, звичайне життя) і **Persona B** (анонімна, Tor завжди) **НІКОЛИ не перетинаються**.
- ❌ НЕ логінься в A-акаунт (Gmail, банк, Samsung), коли ти у стелс / Persona-B. Один вхід — і анонімність впала.
- ❌ НЕ змішуй у часі: не роби A-справи, а одразу B-справи на тій самій мережі/сесії (кореляція).

## 2. Браузинг (головна слабка ланка)
- ✅ Анонімне — **тільки Tor Browser** (+ built-in obfs4 мости, див. нижче). Звичайний браузер через системний SOCKS **тече DNS/WebRTC** → видасть реальний IP.
- ❌ У Tor Browser: не логінься в особисті акаунти, не став розширення, **не міняй розмір вікна** (fingerprint).
- ✅ A-життя — звичайний браузер; не чекай анонімності, коли залогінений.

## 3. Стелс-режим (перемикач 🥷 у меню-барі)
- ✅ **ON** для B / чутливого / чужої мережі. Перевір **🥷** в меню-барі ПЕРЕД чутливою роботою.
- ⚠️ У Persona-B стелсі — **Samsung геть/вимкнений** (його Bluetooth поруч прив'язує анонімну сесію до реального тебе; TETHER на Samsung у Persona-B не використовуй).
- ✅ Звичайне життя — **OFF** (як у всіх), без сорому.

## 4. CHIMERA
- ✅ Тримай живою (8/8). Довіряй, але перевіряй через **журнал-аудит**.
- ⚠️ Це **НЕ антивірус**. macOS оновлюй (XProtect/Gatekeeper), **SIP не вимикай**, LuLu — deny-by-default (і дозволь CHIMERA назовні для CHAFF).
- ⚠️ **PURGE** — лише свідомо (arm+trigger), ніколи «про всяк випадок».

## 5. Системна гігієна
- ✅ Оновлюй macOS + застосунки (патчі — головний захист від малвару).
- ✅ FileVault on. У LuLu дозволяй ТІЛЬКИ те, що знаєш.
- ❌ Не запускай неперевірені / «крякнуті» бінарники — це обходить усе вище.

## 6. Сховати сам факт Tor (мости)
- ✅ **Tor Browser → Settings → Connection → Bridges → Select a Built-In Bridge → obfs4.** Тоді ISP бачить не «Tor», а звичайний-схожий трафік. Безпечно, один клік, нуль ризику для системи.
- ⚙️ Системний SOCKS-tor можна теж пустити через мости — але це правка root-torrc + перезапуск живого tor (ризик). Робити обережно, з бекапом.

## 7. Чесні межі (без ілюзій)
- Маскування ≠ 100% невидимість: лишаються fingerprint + поведінка.
- Tor має кореляційні атаки (глобальний пасивний ворог) — проти держ-рівня сам не рятує.
- macOS — закритий периметр. Для максимуму анонімності — окреме загартоване залізо (Tails/Whonix/GrapheneOS) + ця дисципліна.
